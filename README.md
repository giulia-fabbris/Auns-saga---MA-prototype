# Digital Edition Prototype: *Áns saga* (AM 343 a 4to)

This repository contains a digital scholarly edition prototype developed as part of my MA thesis in Germanic Philology (2018). It serves as a technical proof of concept to demonstrate the pipeline from XML-TEI text encoding to web visualization using the EVT 2 framework.

## Academic Publications & References
The theoretical framework, philological commentary, and technical methodology behind this prototype have been documented and discussed in the following academic publications:

- 📝 **Project Report / Journal Article:** [Áns Saga Bogsveigis – an Editorial Study and a Prototype for a Digital Edition](https://umanisticadigitale.unibo.it/article/view/10590) (Published 2020, Peer-Reviewed)
- 📄 **MA Thesis Publication:** [A Literary and Editorial Study of Áns Saga Bogsveigis](https://unitesi.unive.it/handle/20.500.14247/10730) (Official University Repository, 2018)

## Project Status & Methodological Note
This is a **legacy academic project** and serves primarily as a showcase of technical skills and methodology in Digital Humanities. As a prototype, the text encoding and editorial choices reflect that specific stage of research and are not currently subject to active updates or revisions.

### Note on Digital Facsimiles & Copyright
Digital facsimiles of the original manuscript are not included in this repository due to institutional copyright restrictions. 

- In this live demo, standard **placeholders** have been implemented to preserve the layout, text-image alignment, and overall architecture of the EVT 2 framework.
- The original digitized manuscript and its full photographic plates can be consulted directly on the official portal: [Handrit.is — AM 343 a 4to (Folio 81v)](https://handrit.is/manuscript/view/is/AM04-0343a/171?iabr=on#page/81v/mode/2up).

## Technical Stack
- **Encoding Standard:** XML-TEI (P5)
- **Visualization Framework:** EVT 2 (Edition Visualization Technology)
- **Architecture:** Angular-based web application
- **Hosting:** GitHub Pages
